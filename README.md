# 끼리맘 (Kkirimom)

엄마와 AI가 함께 육아 고민을 나누는 방.

임신·출산부터 신생아 수유·수면, 이유식·발달, 건강·병원, 준비물, 나들이·여행까지 — 육아맘 전용 AI와 사람이 한 방에서 같이 이야기하는 서비스입니다.

- 주소: https://kkirimom.com/  (GitHub Pages: https://gcchon84.github.io/kkirimom/)
- 만든 곳: 육오빠 · https://brand.naver.com/65ppa

## 이용

- 회원: 방·대화 무제한 무료
- 게스트: 방 1개 · 끼리맘 AI 10회 체험

## 안전 안내

AI 답변은 일반 육아 참고용이며 의사의 진단·치료를 대신하지 않아요. 아기가 아프거나 응급 시에는 반드시 소아과·119에 문의해 주세요.

## 파일

- `index.html` — 앱 전체 (단일 파일)
- `manifest.webmanifest` · `sw.js` — 홈 화면에 추가(설치)
- `icon-192.png` · `icon-512.png` · `apple-touch-icon.png` · `favicon.png` — 앱 아이콘
- `logo-mark.png` · `logo-full.png` — 로고(ㄲ+아기+ㄹ / 워드마크 포함, 투명 배경)
- `og-image.png` — 카카오톡·링크 미리보기 이미지
- `make_brand_assets.py` — 원본 로고 이미지에서 위 이미지들을 다시 만드는 스크립트
